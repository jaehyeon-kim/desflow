# desflow report

The help of `desflow report`, generated from the command's code. [Command Line](https://jaehyeon.me/desflow/latest/cli/#compare-designs) uses this one on the shop, and its [What It Is](https://jaehyeon.me/desflow/latest/cli/#what-it-is) lists every command.

```text
Usage: desflow report [OPTIONS] {FOLDER}

  Build the report of an experiment again from the artifacts in FOLDER.

Arguments:
  FOLDER  An experiment's output folder, with its experiment.json.  [required]

Options:
  --help  Show this message and exit.

  Examples:

    # Build the report again from an experiment's results

    $ desflow report results
```
