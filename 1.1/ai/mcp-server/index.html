    MCP Server

    desflow mcp serves the desflow commands as tools to an AI assistant on the same machine. MCP, the Model Context Protocol, lets an assistant find the tools of a server and call them, each with named parameters. The assistant's MCP client starts desflow mcp as a process and exchanges messages with it over the process's standard input and output. Each tool runs one desflow command, named in the tables below, in the server's process, so it checks and refuses its arguments as the command does.

    The plugin starts the server for Claude Code, Codex and Antigravity, with the skill. This page sets the server up for another assistant, or for one without the plugin, and calls its tools from a Python script.

    Install

    The server needs the mcp extra:

    docs/snippets/integrations/commands.sh:install-uv
    1
    uv tool install "desflow[mcp]>=1.1"
    docs/snippets/integrations/commands.sh:install-pip
    1
    pip install "desflow[mcp]>=1.1"

    Without the extra, desflow mcp exits with an error that names the pip install command. The scripts on this page also import the mcp package, so run them where pip install "desflow[mcp]>=1.1" installed it, such as a virtual environment of their own. uv tool install keeps desflow in an environment that a script cannot import from.

    Tools That Write Nothing

    The server always offers these seven tools. They write nothing themselves, but check, explain and test load a Python builder file by running its code, which can write files, so give them only builder files you trust. Each takes the arguments and options of its command as parameters, with the same names, and variables fills ${NAME} in a blueprint as --var does:

    Tool Command Returns
    check desflow check what the command prints
    explain desflow explain --json the JSON document that the command prints
    test desflow test what the command prints
    fit desflow fit, which needs the fit extra what the command prints
    dist desflow dist what the command prints
    schema desflow schema the blueprint JSON Schema
    list_examples desflow examples list what the command prints

    A tool that returns a JSON document gives it as the result's structured content and as text. A tool that returns what the command prints gives its warnings first. A tool whose command fails returns an error with the command's message. The server runs one tool at a time.

    Tools That Write

    desflow mcp --allow-changes also offers four tools, and three parameters of two tools above:

    Tool Command Returns
    run desflow run --summary the JSON document that --summary writes: the run's statistics, or with replications the seeds, the summary and each replication's values
    experiment desflow experiment what the command prints
    report desflow report what the command prints
    get_example desflow examples get what the command prints

    test gains fix, which writes the statistics into the expected values that differ, and fit gains out and plot, which write the best fit and a picture of the fits. A run sends its records to the blueprint's sinks, such as a Kafka topic or a table, and the other tools write files. The server marks the four tools, and test and fit when it offers their writing parameters, as destructive, and the others as read-only, so a client can ask before it runs one. The plugin starts the server without the option. Add the option to an assistant's settings only for a project whose sinks it may write to. The option is part of the server's entry in the assistant's settings, so a project that shares that file shares the option.

    Write the Result to a File lists the keys of the run tool's document.

    Add It to an Assistant

    The server needs the command desflow and the argument mcp. It reads a relative path in a tool call from the folder the client starts it in, which the client chooses, so ask for absolute paths when a tool does not find a file.

    In Claude Code, run this in the project's folder, to add the server for that project:

    import sys

import anyio
from mcp import Client, StdioServerParameters


async def main(command):
    """Print the name and description of each tool the server offers.

    Args:
        command: The command that starts the server, as a list of words.
    """
    server = StdioServerParameters(command=command[0], args=command[1:])
    async with Client(server) as client:
        for tool in (await client.list_tools()).tools:
            print(f"{tool.name}: {tool.description}")


anyio.run(main, sys.argv[1:])

    import anyio
from mcp import Client, StdioServerParameters

# The rows of the run's statistics to print
FIGURES = (
    "tasks.pack.finished",
    "tasks.pack.wait_mean",
    "resources.packers.utilization_avg",
)


async def call(client, name, arguments):
    """Call one tool and stop on an error.

    A tool that fails returns its error as the result, so the call checks for it.

    Args:
        client: The connected MCP client.
        name: The tool to call.
        arguments: The tool's parameters.

    Returns:
        The tool's result.

    Raises:
        RuntimeError: When the tool returns an error.
    """
    result = await client.call_tool(name, arguments)
    if result.is_error:
        raise RuntimeError(f"{name}: {result.content[0].text}")
    return result


async def main():
    """Check the shop, explain it, then run it with three packers."""
    server = StdioServerParameters(command="desflow", args=["mcp", "--allow-changes"])
    async with Client(server) as client:
        checked = await call(client, "check", {"files": ["shop.yaml"]})
        # check returns what the command prints, warnings first
        print("--- check")
        print(checked.content[0].text.splitlines()[-1])

        explained = await call(client, "explain", {"source": "shop.yaml"})
        # explain returns the document of desflow explain --json
        print("--- explain")
        for hint in explained.structured_content["hints"]:
            print(hint["text"])

        ran = await call(
            client,
            "run",
            {
                "file": "shop.yaml",
                "until": "3600",
                "seed": 7,
                "variables": {"PACKERS": "3"},
            },
        )
        # run returns the summary that desflow run --summary writes
        print("--- run")
        statistics = ran.structured_content["statistics"]
        print(
            {
                row["statistic"]: row["value"]
                for row in statistics
                if row["statistic"] in FIGURES
            }
        )


anyio.run(main)
