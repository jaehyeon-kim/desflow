# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | yes |
| below 1.0 | no |

A fix, including a security fix, ships in a new 1.x release. The [Compatibility Policy](https://jaehyeon.me/desflow/latest/about/compatibility/) says which Python versions and platforms 1.x supports.

## Report a Vulnerability

Report a vulnerability privately, not in a public issue. On the [Security tab](https://github.com/jaehyeon-kim/desflow/security) of jaehyeon-kim/desflow, choose **Report a vulnerability**, which opens a private report that only the maintainer can read. Give the desflow version, what an attacker can do, and the steps or a model that shows it.

When the vulnerability is confirmed, the fix ships in a new 1.x release, and a GitHub security advisory describes it.
