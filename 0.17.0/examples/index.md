# Examples

Each example is written three ways: as a YAML blueprint, with the declarative API and with the low-level API. Its page shows the versions in tabs.

| Example                                                                                                       | What it shows                                                        | YAML                                                                                                                        | Declarative                                                                                                                           | Low-level                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [Local Simulation](https://jaehyeon.me/dynamic-des/latest/examples/local/index.md)                            | prints events and telemetry, with no container                       | [`local.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/local.yaml)                              | [`local_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/declarative/local_example.py)                     | [`local_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/imperative/local_example.py)                     |
| [Kafka Digital Twin](https://jaehyeon.me/dynamic-des/latest/examples/kafka/index.md)                          | takes updates from Kafka and publishes events and telemetry to Kafka | [`kafka.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/kafka.yaml)                              | [`kafka_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/declarative/kafka_example.py)                     | [`kafka_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/imperative/kafka_example.py)                     |
| [Fast-Forward to Parquet](https://jaehyeon.me/dynamic-des/latest/examples/parquet/index.md)                   | a week generated at `factor=0.0`, written to Parquet                 | [`parquet.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/parquet.yaml)                          | [`parquet_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/declarative/parquet_example.py)                 | [`parquet_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/imperative/parquet_example.py)                 |
| [Fast-Forward to Iceberg](https://jaehyeon.me/dynamic-des/latest/examples/iceberg/index.md)                   | a day generated at `factor=0.0`, appended to an Iceberg table        | [`iceberg.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/iceberg.yaml)                          | [`iceberg_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/declarative/iceberg_example.py)                 | [`iceberg_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/imperative/iceberg_example.py)                 |
