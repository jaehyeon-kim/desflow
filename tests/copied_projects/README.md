# Copied Projects

Copies of the code and data that tests load from other projects, so the tests need no other repository. The tests read these files and never change them, and lint and type checks leave the folder out. To refresh a copy, copy the same files from a later commit of its project and change the commit below.

- `benchtop/`: the modules and data that `tests/benchtop` and the BT known cases (`tests/known_cases/bt_*`) load, from https://github.com/jaehyeon-kim/benchtop at commit `a72fbf9`. The files are copied unchanged, apart from `product-recommender/data/world_pop.csv`, which keeps only the header and the rows of Melbourne, Australia, the city the recommender reads (`recommender/core/config.py`, `CITY`). The data files `product_features.csv`, `user_features.csv` and `users.csv` are generated by the project and not tracked there, so they are copied from a local run.
- `oml-digital-twin-hotrolling/`: the `sim_control` modules that the HR known cases (`tests/known_cases/hr_01`) run, from https://github.com/jaehyeon-kim/oml-digital-twin-hotrolling at commit `0d2f37b`, unchanged, with the project's MIT licence.
