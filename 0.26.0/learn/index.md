# Learn

Each page here teaches discrete-event simulation (DES), and how desflow does it, to a reader new to both. What Is DES? explains the idea with no maths. The tutorial then builds one model of a packing shop through a whole study, so read its pages in order. The Simulation Concepts pages explain the theory behind the tutorial's steps. If you already know SimPy, see [SimPy and desflow](https://jaehyeon.me/desflow/latest/simpy/index.md). To look up one part of desflow, see the [User Guide](https://jaehyeon.me/desflow/latest/user-guide/index.md). To do one task step by step, see [How-To](https://jaehyeon.me/desflow/latest/how-to/index.md).
