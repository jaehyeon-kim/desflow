# desflow

**Realistic event streams from a simulation you can steer while it runs.**

Most test data generators write random rows. desflow writes the events of a working process: orders queue for packers, waits grow at busy times, and a backlog builds when orders arrive faster than the packers can pack them. The data comes from a [SimPy](https://simpy.readthedocs.io/) discrete-event simulation, so each change in it has a cause in the model, as in a real system. [Why desflow](https://jaehyeon.me/desflow/latest/about/why-desflow/index.md) explains why it was built and what it is for.

The three ways to write a model build one real-time run. Ingress connectors change its live parameters while it runs, and egress connectors write its events and telemetry:

## Commands

The package comes with the `desflow` command. It runs a blueprint, and checks, compares and fits models, with no Python to write. [Command Line](https://jaehyeon.me/desflow/latest/cli/index.md) uses every command on the shop of the `experiment` example.

| Command              | What you use it for                                                         | How to use it                                                                                    | Reference                                                                                                                                                                                                                                                        |
| -------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `desflow examples`   | list the examples with `list`, and download one with `get`                  | [Get an Example](https://jaehyeon.me/desflow/latest/cli/#get-an-example)                         | [`desflow examples`](https://jaehyeon.me/desflow/latest/cli/examples/index.md), [`desflow examples list`](https://jaehyeon.me/desflow/latest/cli/examples-list/index.md), [`desflow examples get`](https://jaehyeon.me/desflow/latest/cli/examples-get/index.md) |
| `desflow explain`    | check a model for bottlenecks before a long run                             | [Check It Before a Long Run](https://jaehyeon.me/desflow/latest/cli/#check-it-before-a-long-run) | [`desflow explain`](https://jaehyeon.me/desflow/latest/cli/explain/index.md)                                                                                                                                                                                     |
| `desflow run`        | run a blueprint, or its replications with a 95% interval for each statistic | [Run It](https://jaehyeon.me/desflow/latest/cli/#run-it)                                         | [`desflow run`](https://jaehyeon.me/desflow/latest/cli/run/index.md)                                                                                                                                                                                             |
| `desflow experiment` | compare designs of a model and check them against bounds                    | [Compare Designs](https://jaehyeon.me/desflow/latest/cli/#compare-designs)                       | [`desflow experiment`](https://jaehyeon.me/desflow/latest/cli/experiment/index.md)                                                                                                                                                                               |
| `desflow report`     | build an experiment's report again from its files                           | [Compare Designs](https://jaehyeon.me/desflow/latest/cli/#compare-designs)                       | [`desflow report`](https://jaehyeon.me/desflow/latest/cli/report/index.md)                                                                                                                                                                                       |
| `desflow fit`        | fit every distribution family to measured times                             | [Fit Measured Times](https://jaehyeon.me/desflow/latest/cli/#fit-measured-times)                 | [`desflow fit`](https://jaehyeon.me/desflow/latest/cli/fit/index.md)                                                                                                                                                                                             |
| `desflow dist`       | turn a mean and a standard deviation into a family's parameters, and back   | [Convert Parameters](https://jaehyeon.me/desflow/latest/cli/#convert-parameters)                 | [`desflow dist`](https://jaehyeon.me/desflow/latest/cli/dist/index.md)                                                                                                                                                                                           |
