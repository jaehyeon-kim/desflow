# desflow schema

The help of `desflow schema`, generated from the command's code. [Command Line](https://jaehyeon.me/desflow/latest/cli/#set-up-an-editor) uses this one on the shop, and its [What It Is](https://jaehyeon.me/desflow/latest/cli/#what-it-is) lists every command.

```text
Usage: desflow schema [OPTIONS]

  Print the blueprint JSON Schema.

Options:
  --help  Show this message and exit.

  Examples:

    # Save the blueprint schema for an editor

    $ desflow schema > blueprint.schema.json
```
