# Examples

Each example is written three ways: as a YAML blueprint, with the builder API and with the low-level API. Its page shows the versions in tabs.

| Example | What it shows | YAML | Builder | Low-level |
| --- | --- | --- | --- | --- |
| [Local Simulation](local.md) | prints events and telemetry, with no container | [`local.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/local.yaml) | [`local_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/local_example.py) | [`local_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/local_example.py) |
| [Kafka Digital Twin](kafka.md) | takes updates from Kafka and publishes events and telemetry to Kafka | [`kafka.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/kafka.yaml) | [`kafka_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/kafka_example.py) | [`kafka_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/kafka_example.py) |
| [Fast-Forward to Parquet](parquet.md) | a week generated at `factor=0.0`, written to Parquet | [`parquet.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/parquet.yaml) | [`parquet_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/parquet_example.py) | [`parquet_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/parquet_example.py) |
| [Fast-Forward to Iceberg](iceberg.md) | a day generated at `factor=0.0`, appended to an Iceberg table | [`iceberg.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/iceberg.yaml) | [`iceberg_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/iceberg_example.py) | [`iceberg_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/iceberg_example.py) |
| [Relational DB (Postgres)](postgres.md) | writes orders to PostgreSQL and takes updates from a table | [`postgres.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/postgres.yaml) | [`postgres_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/postgres_example.py) | [`postgres_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/postgres_example.py) |
| [In-Memory Store (Redis)](redis.md) | writes to a Redis Stream and takes updates from Pub/Sub | [`redis.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/redis.yaml) | [`redis_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/redis_example.py) | [`redis_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/redis_example.py) |
| [Backfill Then Go Live](backfill-live.md) | backdated history to Parquet, then live to Kafka | [`backfill_live.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/backfill_live.yaml) | [`backfill_live_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/backfill_live_example.py) | [`backfill_live_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/backfill_live_example.py) |
| [Generate Related Records](advanced-postgres-orders.md) | orders and their line items, in two PostgreSQL tables | [`postgres_orders.yaml`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/yaml/advanced/postgres_orders.yaml) | [`postgres_orders_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/builder/postgres_orders_example.py) | [`postgres_orders_example.py`](https://github.com/jaehyeon-kim/dynamic-des/blob/main/examples/low-level/postgres_orders_example.py) |

Each example page says how to download and run it, and which odctl profile from [Getting Started](../getting-started.md#services-for-the-examples) it needs.
