# How-To

Each page here does one task, step by step, with code that you can run. To see what a part of desflow does and all its options, see the [User Guide](../user-guide/index.md). For a complete model to download and run, see [Runnable Examples](../examples/index.md).

| Group | What it covers |
| --- | --- |
| [Modelling](time-varying-arrivals.md) | arrival rates and staffing that change at set times, tasks that leave a queue or refuse to join it, waits for the first or all of several things, handoffs between resources, a resource shared by weight, breakdowns and repairs, and resources added during a run |
| [Records and Kafka](complex-routing.md) | records routed to Kafka topics, Avro and Pydantic records, secure Kafka connections, and connectors of your own |
| [Analysis](fit-a-distribution.md) | distributions fitted to measured times, checks against the queueing formulas, tests for a model, and a run's event log, analysed and animated |
| [Tools](yaml-advanced.md) | Python logic in a blueprint, completion and checks for blueprints in an editor, an AI coding assistant, and the fastest data generation |
