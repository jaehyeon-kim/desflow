# How-To

Each page here does one task, step by step, with code that you can run. To see what a part of desflow does and all its options, see the [User Guide](../user-guide/index.md). For a complete model to download and run, see the Runnable Examples group.

| Group | What it covers |
| --- | --- |
| [Modelling](modelling/time-varying-arrivals.md) | arrival rates and staffing that change at set times, tasks that leave a queue or refuse to join it, waits for the first or all of several things, handoffs between resources, a resource shared by weight, breakdowns and repairs, and resources added during a run |
| [Records and Kafka](records-and-kafka/complex-routing.md) | records routed to Kafka topics, Avro, JSON Schema, Protobuf and Pydantic records, secure Kafka connections, and connectors of your own |
| [Analysis](analysis/fit-a-distribution.md) | distributions fitted to measured times, checks against the queueing formulas, tests for a model, and a run's event log, analysed and animated |
| [Tools](tools/yaml-advanced.md) | Python logic in a blueprint, completion and checks for blueprints in an editor, an AI coding assistant, and the fastest data generation |
| [Runnable Examples](examples/index.md) | complete models to download and run: a local simulation, a Kafka digital twin, history written fast to Parquet or Iceberg, PostgreSQL, Redis, history then live records, and related records |
