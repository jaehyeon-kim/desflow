# desflow schema

The help of `desflow schema`, generated from the command's code. [CLI](https://jaehyeon.me/desflow/latest/reference/cli/index.md) lists every command, and [Command Line](https://jaehyeon.me/desflow/latest/user-guide/command-line/#set-up-an-editor) uses this one on the shop.

```text
Usage: desflow schema [OPTIONS]

  Print the blueprint JSON Schema.

Options:
  --help  Show this message and exit.

  Examples:

    # Save the blueprint schema for an editor

    $ desflow schema > blueprint.schema.json
```
