# desflow report

The help of `desflow report`, generated from the command's code. [CLI](https://jaehyeon.me/desflow/latest/reference/cli/index.md) lists every command, and [Command Line](https://jaehyeon.me/desflow/latest/user-guide/command-line/#compare-designs) uses this one on the shop.

```text
Usage: desflow report [OPTIONS] {FOLDER}

  Build the report of an experiment again from the artifacts in FOLDER.

Arguments:
  FOLDER  An experiment's output folder, with its experiment.json.  [required]

Options:
  --help  Show this message and exit.

  Examples:

    # Build the report again from an experiment's results

    $ desflow report results
```
