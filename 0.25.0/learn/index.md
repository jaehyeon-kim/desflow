# Learn

Each page here teaches discrete-event simulation (DES), and how desflow does it, to a reader new to both. The pages from What Is DES? to Coming from SimPy explain the ideas. The tutorial then builds one model of a packing shop through a whole study, so read its pages in order. To look up one part of desflow, see the [User Guide](https://jaehyeon.me/desflow/latest/user-guide/index.md). To do one task step by step, see [How-To](https://jaehyeon.me/desflow/latest/guides/index.md).
