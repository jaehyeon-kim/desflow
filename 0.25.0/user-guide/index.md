# User Guide

Each page here describes one part of desflow: what it does, how to use it, how it works and its limits. Read a page when you need that part. To learn DES and desflow from the start, follow [Learn](https://jaehyeon.me/desflow/latest/learn/index.md) instead. To do one task step by step, see [How-To](https://jaehyeon.me/desflow/latest/guides/index.md).

| [Writing a Model](https://jaehyeon.me/desflow/latest/user-guide/ways-to-write/index.md)            | the three ways to write a model: a YAML blueprint, the builder API and the low-level API                          |
