# How-To

Each page here does one task, step by step, with code that you can run. To see what a part of desflow does and all its options, see the [User Guide](https://jaehyeon.me/desflow/latest/user-guide/index.md). For a complete model to download and run, see [Runnable Examples](https://jaehyeon.me/desflow/latest/examples/index.md).

| Group                                                                                   | What it covers                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Modelling](https://jaehyeon.me/desflow/latest/guides/time-varying-arrivals/index.md)   | arrival rates and staffing that change at set times, tasks that leave a queue or refuse to join it, waits for the first or all of several things, handoffs between resources, a resource shared by weight, breakdowns and repairs, and resources added during a run |
| [Records and Kafka](https://jaehyeon.me/desflow/latest/guides/complex-routing/index.md) | records routed to Kafka topics, Avro and Pydantic records, secure Kafka connections, and connectors of your own                                                                                                                                                     |
| [Analysis](https://jaehyeon.me/desflow/latest/guides/fit-a-distribution/index.md)       | distributions fitted to measured times, checks against the queueing formulas, tests for a model, and a run's event log, analysed and animated                                                                                                                       |
| [Tools](https://jaehyeon.me/desflow/latest/guides/yaml-advanced/index.md)               | Python logic in a blueprint, completion and checks for blueprints in an editor, an AI coding assistant, and the fastest data generation                                                                                                                             |
