# dynamic-des is now desflow

The package dynamic-des is renamed [desflow](https://pypi.org/project/desflow/) from version 0.20.0. This last release of dynamic-des installs desflow, with the same extras.

Install desflow directly:

```bash
pip install desflow
```

Then import `desflow` instead of `dynamic_des`, and run the `desflow` command instead of `ddes`. The old import and the old command still work in desflow, with a warning, and are removed in a later release.

The documentation is at [jaehyeon.me/desflow](https://jaehyeon.me/desflow/), and the code at [github.com/jaehyeon-kim/desflow](https://github.com/jaehyeon-kim/desflow).
