    Cheat Sheet

    The common YAML keys and builder calls side by side, each linked to the page that explains it. YAML Format lists every key, and the API Reference every call. In the builder column, app is a SimulationContext, and a task's settings are arguments of @app.task(...).

    Simulation

    To YAML Builder Read
    Name the model and set the clock simulation: {sim_id, factor, random_seed} SimulationContext(sim_id, factor=, random_seed=) Time and Pacing
    Leave the start of a run out of the statistics simulation.warmup SimulationContext(warmup=) Statistics
    Start the clock at a time other than 0 simulation.initial_time SimulationContext(initial_time=) Run Length
    Print the JSON Schema of a blueprint desflow schema none Set Up Your Editor
    Write timestamps in a time zone simulation.timezone SimulationContext(timezone=) Records and Telemetry

    Arrivals and Services

    To YAML Builder Read
    Draw a service time services: {packing: {dist: normal, mean: 3, std: 0.5}} app.add_service("packing", dist="normal", mean=3, std=0.5) Arrivals and Services
    Start a task at random gaps arrivals: {orders: {dist: exponential, rate: 0.5, spawn: pack}} app.add_arrival("orders", dist="exponential", rate=0.5) and an arrival_loop Arrivals and Services
    Give each entity attributes arrivals.<name>.attributes app.add_arrival(..., attributes={...}) Task Flow
    Replay recorded arrivals arrivals.<name>.replay: {path, time} app.add_arrival_replay(name, source) Local Replay
    Fit a service time to data desflow fit, then !include fit_column(values) Input Fitting

    Resources, Stores and Containers

    To YAML Builder Read
    Add staff or machines resources: {packers: {current_cap: 2, max_cap: 4}} app.add_resource("packers", current_cap=2, max_cap=4) Resources
    Declare a resource with one unit, or none to wait for resources: {packers: {}}, or {current_cap: .inf} for no limit app.add_resource("packers"), or current_cap=float("inf") Resources
    Refuse a request when the line is long queue_limit: 5 add_resource(..., queue_limit=5) Patience
    Read how many units are held or wait users.packers, queue.packers in a condition context.get_resource("packers").count, .users, .queue Resources
    Build a resource from your own class type: !python shop_logic.MyPackers add_resource(..., type=MyPackers) Custom Resource Types
    Serve by priority queue: priority and a task's priority add_resource(..., queue="priority") and @app.task(priority=) Priorities
    Let urgent work take a busy unit preempt: true add_resource(..., preempt=True) Interruptions
    Make a resource fail and be repaired resources.<name>.breakdown app.add_breakdown(resource, time_to_failure=, repair=) Breakdowns
    Hold an amount, such as boxes containers: {stock: {current_cap, max_cap, level, type}} app.add_container("stock", current_cap, max_cap, level=, type=) Stores and Containers
    Hold items, such as parcels stores: {parcels: {current_cap, max_cap, items, type}} app.add_store("parcels", current_cap, max_cap, items=, type=) Stores and Containers

    Tasks

    To YAML, under tasks.<name> Builder, in @app.task(...) Read
    Take a service time while holding a resource service, resource service_id=, resource_id= Tasks and Processes
    Publish a payload when finished payload the function's return value Tasks and Processes
    Take from or add to a store or container get, put get=, put= Stock
    Go on to another task next next= Task Flow
    Give up waiting, or refuse to join patience, balk patience=, balk= Patience
    Wait for a signal, a task, a timeout or a condition wait wait= Process Interaction
    Wait for a running task, or a timeout with a value wait: {running: {task}}, wait: {timeout: {after, value}} the same in wait= Signals and Waiting
    Wait for at least some of several branches, or nest groups wait: {at_least: 2, of: {a: ..., b: ..., c: ...}}, or any and all inside each other the same in wait= Wait for One or All
    Wait for a unit, an item or room, as one branch of a wait wait: {any: {unit: {request: packers}, limit: {timeout: 30 s}}}, {get: {store: parcels}}, {put: {store: parcels}} the same in wait= Signals and Waiting
    Make a put or get without waiting for it put: {container: tank, amount: 40, wait: false} put={"container": "tank", "amount": 40, "wait": False} Stores and Containers
    Read the puts and gets waiting, or the items held putters.lane, getters.lane, count(parcels), items(parcels, item.sku) in a condition the same in wait={"condition": ...} Stores and Containers
    Fire a signal, or fail signal, fail, on_fail signal=, fail=, on_fail= Signals and Waiting
    Fire a signal once signals: {closing: {once: true}} add_signal(name, once=True) Signals and Waiting
    Start a new flow, now or after a delay spawn: {task, after} spawn=, or context.spawn(gen, delay=) Signals and Waiting
    Be told when a flow ends subscribe: {task} subscribe=, or context.subscribe(event) Signals and Waiting
    Run actions when a task or signal fires on: [{fire}, {spawn}, {interrupt}] on= on @app.task and add_signal Signals and Waiting
    Interrupt other tasks interrupt, on_interrupt interrupt=, on_interrupt= Interruptions
    Hold several resources resource: [picker, bench], keep resource_id=["picker", "bench"], keep= Competing Resources

    Changes During a Run

    To YAML Builder Read
    Change a parameter at a time scenario: [{at, path, value}] app.add_step(at, path=, value=) Changing Demand
    Change it from Kafka, Redis or PostgreSQL ingress app.add_ingress(...) Live Parameters
    Publish a ground-truth label scenario: [{at, record}] app.add_step(at, record=) Live Parameters

    Statistics and Sinks

    To YAML Builder Read
    Publish built-in statistics stats: {level: basic, interval: 10} app.with_stats("basic", interval=10) Statistics
    Send records to a sink egress: [{type: Kafka, config: {...}}] app.add_egress(KafkaEgress(...)) Egress
    Send history and live records to different sinks egress[].when: history or live add_egress(..., when="history") Parquet History, Kafka Live

    Run

    To YAML Builder Read
    Run to a time run: {until: 1 h} app.run(until=3600) Time and Pacing
    Stop at a signal or a condition run.stop app.run(until=, stop=) End Conditions
    Finish the entities already in the model run.drain: true app.run(until=, drain=True) End Conditions
    Run in segments, then finish not in YAML app.start(), app.advance(until), app.finish() Run Length
    Raise when the run falls behind the wall clock simulation: {strict: true} SimulationContext(strict=True) Clocks and Pacing
    Fire a one-shot signal first at its time, or later on: [{fire: {signal: s, urgent: true, after: 5 s}}] @app.task(on=[{"fire": {"signal": "s", "urgent": True, "after": 5}}]) Signals and Waiting
    Run on your own environment class simulation: {environment: !python mod.Env} SimulationContext(environment=Env) Blueprints
    Stop the run on a failure nobody handles run: {on_unhandled_failure: stop} app.run(on_unhandled_failure="stop") Failures
    Repeat a run with other seeds desflow run FILE --replications 20 replicate(model, 20, seed=, until=) Replications
    Compare designs desflow experiment FILE run_experiment(spec) Experiments
